# 0003 – SQLite for state, runs and events

- Status: accepted
- Date: 2026-09-24

## Decision

`bun:sqlite` in WAL mode with Drizzle. Migrations generated by drizzle-kit are imported as text
(`src/db/migrations.gen.ts`) and applied by a small migrator, so they live inside the binary.

## Consequences

CLI and daemon can share the file (`busy_timeout`). Run events are append-only rows keyed by
`(run_id, seq)`, which makes resuming streams a range query.
